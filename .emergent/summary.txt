<product_requirements>
The goal is to build a full-stack web application to manage the daily operations of a bakso (meatball) business. The system must run on a Raspberry Pi.

**Core Features Implemented:**
- **Stock-First Workflow:** The primary data entry method is through a Stock Management page. The user inputs the initial stock at the start of the day and the remaining stock at the end. The system automatically calculates items sold and the corresponding revenue.
- **Stock Editing:** Users can view and edit previously entered initial and remaining stock data.
- **Complex Sales Transactions:** A dedicated page allows for recording sales of predefined packages, with the ability to add extra condiments (e.g., bakso kecil, tahu). These condiments have specific, non-linear pricing tiers (e.g., 1 for Rp 2000, 2 for Rp 3000, 4 for Rp 5000).
- **Financial Dashboard:** Automatically calculates and displays daily summaries, including total revenue, production costs, fixed costs (rent, salaries), net profit, and employee bonuses based on a specified formula.
- **Expense Tracking:** A feature to log unexpected expenses, which are factored into the daily profit calculation.
- **Data Export:** Functionality to export daily summaries, monthly reports, and stock data to Excel files.

**Deployment Requirement:** The application must be deployable on a memory-constrained Raspberry Pi 3B. This led to a final requirement for a lite installation package that uses a single setup script to avoid on-device compilation and memory exhaustion.
</product_requirements>
